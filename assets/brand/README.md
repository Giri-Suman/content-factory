# assets/brand/

The brand kit. Everything in here must be original or licensed — this
directory is the reason the channel never gets a copyright strike.

- `palette.json` — 2–3 brand colors (decided in P0 homework)
- `logo/` — channel mark, avatar, banner
- `stings/` — intro/outro loops rendered with the portfolio repo's
  Three.js render-engine
- `sfx/` — whooshes/pops from freesound.org (CC0 only) or YouTube Audio Library
- `music/` — YouTube Audio Library tracks only
