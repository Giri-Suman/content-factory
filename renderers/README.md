# renderers/

Each renderer compiles a `script.json` + voice audio into finished video.

- `code-report/` — **P1** — Remotion. The Fireship-style flagship: kinetic
  text, Shiki code scenes, screenshot pans, terminal replays, stat charts,
  karaoke captions. Outputs 16:9 and 9:16 from the same script.
- `math/` — **P4** — Manim CE. Template library of proven viral formats:
  proof-without-words, paradoxes, graph morphs.
- `shorts/` — **P4** — mines long-form transcripts for hook moments,
  reframes to 9:16 with big captions.
